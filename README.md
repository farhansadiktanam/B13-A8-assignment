## Project Name: SkillSphere

## Description: Pages —

Home, All Courses, Course Details (protected), Login, Register, My Profile, Update Profile, 404
Home features — Swiper.js hero slider, Popular Courses section, Learning Tips section, Top Instructors section, Trending Courses section, CTA banner
Courses — Search by title, filter by category and level, course cards with rating/students/duration
Auth — Email/password login & register, Google OAuth, protected routes with redirect back after login
Profile — View account info + stats, update name and avatar URL
